⭐ Featured · AI / ML

NovaRAG — Offline Multimodal RAG Pipeline

An offline-first, hybrid retrieval-augmented generation pipeline that processes text, images, and documents locally — no cloud dependency. Built to answer complex queries over private data using dense + sparse retrieval.

Python FastAPI FAISS BM25 HuggingFace Ollama
  • Hybrid retrieval: FAISS (dense) + BM25 (sparse) for best-of-both accuracy
  • Fully offline — runs on local LLMs via Ollama, no API keys needed
  • Multimodal support for text and image document chunks
  • REST API via FastAPI for seamless integration
